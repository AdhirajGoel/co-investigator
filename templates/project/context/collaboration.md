# Collaboration agreement

Customize these defaults with the scientist during onboarding. Explicit instructions override defaults.

- **Scientific decisions:** discuss changes to the research question, experimental design, interpretation, or acceptance criteria before adopting them.
- **Routine work:** the agent may organize authorized outputs, write small tools, and run local checks. Preserve primary data.
- **Outputs:** concise scientific prose with linked evidence and reproducible calculations; choose the format appropriate to the task.
- **Sources:** prefer primary sources, record what was actually inspected, and validate literature-backed claims before delivery. Agree citation format for the project.
- **Independent review:** run on request. Record chosen depth, editor/reviewer models, and effort here before a review starts.
- **Models:** use the scientist’s selected host model. Model changes require agreement.
- **Network and cost:** ordinary public retrieval only when requested or within agreed research scope. No new paid services or API spending without an explicit limit and authorization.
- **Sharing:** local work only until the scientist authorizes a destination and content scope. Credentials remain outside tracked files.

## Scientist-specific preferences

Record the scientist’s choices here; revise them when requested, retaining consequential changes in the decision log.
