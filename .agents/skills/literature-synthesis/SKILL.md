# Literature Synthesis

1. Read the current project context and collaboration rules. Establish the question, experimental system, endpoint, and intended decision. Reuse existing source records before retrieving more.
2. Search the relevant primary literature through available connectors or public services. Keep the query, date, identifiers, inclusion rationale, and retrieval status in a source record. Use literature-pdf-download for full texts and read-pdf to inspect them.
3. Record each material claim with its source identifier, supporting page/figure/passage, evidence tier, and the experimental system it actually concerns. A retrieved paper is not automatically read evidence. Distinguish source observations from your inference.
4. Compare alternative explanations, contrary evidence, and what the existing studies cannot distinguish. Do not transfer conclusions between systems or endpoints without an explicit rationale.
5. Write a concise synthesis in `research/` using the agreed format. Link the source records. For each proposed hypothesis, state a distinguishing prediction and what observation would weaken it. Avoid assigning numerical probabilities without a defensible basis.
6. Validate citations. Offer independent review when the scientist requests it or the collaboration agreement requires it. Preserve reviewer independence and the response record.

Use `templates/literature-synthesis.md` as an optional starting point. Record completed work in the log. Update current project context only when the synthesis changes the working view or next decision, with a link to the supporting artifact.
