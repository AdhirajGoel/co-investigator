# Scientific Writing

Read `context/collaboration.md` for audience, output length, citation format, and style preferences. Read [general-writing.md](references/general-writing.md) and [life-sciences-writing.md](references/life-sciences-writing.md) for scientific artifacts.

Use the structure the artifact needs. Preserve source claims, numbers, observations, and uncertainty. Do not add a finding, invent an experiment, or strengthen a causal claim while editing prose. Keep the scientist’s voice and supplied meaning.

Draft directly, then remove repetition, inflated language, unsupported superlatives, and unnecessary framing. Check that each paragraph advances the argument and that captions explain the displayed evidence. Keep references to the underlying analysis alongside numerical results.

Run the project’s citation-validation skill when the artifact contains life-sciences literature claims. Writing review and citation verification have separate outcomes; do not report one as evidence for the other.
