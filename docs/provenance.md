# Origin and adaptations

This release packages collaboration patterns and reusable scientific skills developed through experimental research with coding agents. It contains no original study records, experimental data, sequences, findings, or research figures.

The PDF-reading, literature-download, citation-validation, independent-review, sequence-verification, and writing components are adapted from the author’s reusable personal skills. The source fingerprints in `skill-provenance.json` identify the input assets without publishing private filesystem locations. Release copies use portable paths, explicit project preferences, and validated inputs. Personal installations remain unchanged.

The workspace initializer, project templates, and focused synthesis, experiment-cycle, and tool-building skills make those components usable together in a new project. They encode workflow conventions; they do not demonstrate a measured improvement in research productivity or scientific outcomes.

The code and original documentation are MIT-licensed. Dependencies keep their own licenses. Retrieved papers and user-supplied data are governed by their own rights and are not relicensed by this repository.
